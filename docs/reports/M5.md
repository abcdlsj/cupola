# M5 — deployment and verification

Status: delivered, with the limits listed at the end.

## What ships

- `deploy/Dockerfile.hub` (distroless, non-root, PWA built in),
  `deploy/Dockerfile.agent` (Debian slim + smartmontools),
  `deploy/docker-compose.yml`, `deploy/systemd/{cupola-hub,cupola-agent}.service`.
- `.github/workflows/ci.yml` (Go vet/test/build, web lint/test/build, Playwright
  with Chromium and WebKit) and `.github/workflows/pages.yml` (static PWA with
  the repository base path, `VITE_CUPOLA_HUB` optional).
- Relay: agent exposure and hub dialer through `github.com/abcdlsj/bolthole`;
  the static PWA connects to a hub by URL + read token (`#hub=…&token=…` is
  accepted once and stripped). The dashboard-side Bolthole client from PLAN
  §2.3 is not included in this release; GitHub Pages therefore uses HTTPS.
- `scripts/e2e-hub.sh` starts three fictional agents, a hub and its seed data for
  Playwright; `scripts/seedhub` backfills 24 h of samples for the screenshots.
- `scripts/demoagent` serves the fictional `atlas`, `beelink` and `studio`.
