# M1 — agent

Status: delivered; verified on macOS (reduced collectors) and on `beelink`
(Ubuntu 24.04, amd64) over SSH with a temporary install under `/tmp`.

## What ships

- `cupola agent` — config (JSON, 0600, unknown fields rejected), token file
  (0600), loopback-only by default, `--init`.
- Collectors: gopsutil (host/CPU/memory/disk/network/processes/users), procfs
  (PSI, diskstats, netdev, sockets), ghw (CPU model, cached), ethtool (link
  speed/duplex/driver), go-systemd D-Bus with a `systemctl` fallback, Docker SDK
  over the unix socket, smart.go + `smartctl --json`, go-nvml (`linux && cgo`),
  AMD GPU sysfs, opt-in apt/dnf pending updates, `/proc/sys/fs/file-nr` and
  conntrack.
- Processes: top N (default 40), CPU deltas, RSS, threads, start time, tty, cwd,
  cgroup, container attribution; command arguments are replaced with
  `[N args redacted]`.
- AI roster: 18 types in one registry (coding agents and model servers), matched
  on executable basename plus the ComfyUI/Pi directory rule.
- Ports: `/proc/net/{tcp,tcp6,udp,udp6}` joined to `/proc/*/fd` socket inodes.
- Actions: fixed scripts (no shell, no arguments, fixed cwd, PATH+LANG only,
  process-group kill, 1–60 s, 8 KiB output, one run at a time) and Wake-on-LAN
  (102-byte packet); results become events; the advertised list never includes
  paths, MACs or broadcasts.
- Read-only API with constant-time bearer compare, `/v1/snapshot`,
  part endpoints, `/v1/actions`, run, events and SSE; optional Bolthole exposure.
- Tests: WOL packet shape (UDP listener), script execution, timeout, output
  truncation, redaction, agent registry, config validation and 0600 files.

## Verification

macOS (darwin/arm64, CGO off): snapshot with CPU, memory, load, per-core, disks,
network rates, 40 processes, 7 AI sessions, PSI absent (macOS), services/ports/
SMART/updates empty, no warnings other than the expected Docker socket absence.

beelink (Ubuntu 24.04, 4 cores, amd64, CGO off, non-root):

| Area | Result |

| relay | agent exposed through a local Bolthole relay; relayed `GET /v1/snapshot` returned 200 |

## Known limits

- SMART, full port ownership and container stats need root or group membership.
- NVIDIA needs a cgo build; the release build is CGO-free.
- The macOS build has no systemd, ports, SMART, updates or PSI.
