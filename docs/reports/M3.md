# M3 — web

Status: delivered. The M0 fixture layer is gone; every screen reads the hub API.

## What ships

- TanStack Query over a small API client: same-origin session or a remote hub
  URL + bearer token (stored in localStorage, or bootstrapped from the URL
  fragment for a static PWA and then stripped). SSE via `fetch` invalidates
  queries; polling is the fallback.
- Routes: overview, nodes, node tabs (overview, CPU, memory, storage, network,
  processes, agents, services, containers, apps, events), process/session/unit/
  container/action/event detail pages, fleet agents and apps, events, alerts,
  rule editor, settings (nodes, alerts, tokens, retention, appearance, about).
  All tabs are links; filters live in search params; copy-link on the headers.
- Overview: fleet horizon from real health, finding sentence, KPI strip,
  attention list capped at four, node table, app strip, recent events.
- Node pages: uPlot time series with min/avg/max from the hub, per-core bars,
  pressure/sensor column, disk table, process table, roster grouped by type with
  Warren marks, failed-only services filter, container table, action tiles with
  confirmation and result (danger requires typing the name).
- Alerts: firing/history, rules table, rule editor (metric and event), history,
  deliveries; “Alert me about this” on an event opens a prefilled rule.
- Settings: add/test/remove nodes (direct or Bolthole), channels with test
  delivery, token creation (shown once) with scopes and allowlists, retention
  facts, about/sign-out.
- PWA: manifest, precache, network-first API, last-known fleet snapshot in
  IndexedDB with an offline banner, 100dvh shell with a bottom bar inside the
  visual viewport, safe-area padding, installable.
- `/nodes` remains the table (option A).
