# M0 — design gate report

Status: **awaiting visual approval.** No backend was built in this milestone: the
hub, the agent, SQLite and the API stay at M1–M2, as the plan requires.

## What ships

- Go module `github.com/abcdlsj/cupola` with `cmd/cupola` (subcommand shell,
  `version`), `internal/version`, and tests. `agent`, `hub` and `serve` print an
  explicit not-implemented message until their milestones.
- `web/`: React 19 + TypeScript + Vite 7 + Tailwind v4 scaffold, PWA manifest and
  service worker (`vite-plugin-pwa`), self-hosted Public Sans and IBM Plex Mono,
  the data-terminal token sheet, and the shell (56 px icon rail, 48 px top bar,
  phone bottom bar, ⌘K palette, offline banner).
- Screens: overview with the fleet horizon, nodes list, node overview (CPU chart,
  sensors, disks, processes), agent roster, apps (tiles, confirmation, result),
  about. Node-scoped variants of agents and apps share the same components.
- Fixture snapshot with four fake boxes (`atlas`, `beelink`, `studio`, `shed`)
  behind a Zod schema; totals are derived from the rows and asserted in tests.

## Routes

```
/                          overview (fleet horizon)
/nodes                     nodes list, ?q= filter
/nodes/:nodeId             node overview, ?range=1h|24h|7d
/nodes/:nodeId/agents      roster, scoped to the node
/nodes/:nodeId/apps        actions, scoped to the node
/agents /apps              fleet-wide roster and actions
/settings/about            this build, the direction, what M0 is
```

M0 renders the node tabs it implements (Overview, Agents, Apps). The remaining
node tabs (CPU, Memory, Storage, Network, Processes, Services, Containers,
Events) are M3 work; their routes are not linked yet rather than pointing at
empty screens.

## Design

- **Style:** `data-terminal`, seed `956138436`, dark; sheet in
  `docs/design/direction.json`, tokens in `docs/DESIGN.md` and
  `web/src/styles/tokens.css`.
- **Face:** the **fleet horizon** on the overview. One mark per node on a common
  baseline, height = CPU now, status colour only for degraded/offline, a 1 px
  accent line beside the selected (offline) node, every mark a link. Above it the
  count and the finding sentence; beside it the action the operator is most likely
  to take (“Wake desk”).
- **Second signature:** the agent roster — Warren's marks as 16 px monochrome
  masks, grouped by type, with session counts, aggregate CPU/RAM and the longest
  session. No tinted squares, no brand colours.
- **Screen questions:** overview → “is anything wrong right now?”; nodes → “which
  box is this?”; node → “what is this machine doing and what is filling up?”;
  agents → “what is running, where and for how long?”; apps → “what can I run, and
  did it work?”.

### WARNs and why they stay

- **`hero-void` on `/nodes`** — the list is four rows; with a real fleet of 50 it
  fills the canvas. Filling the space with a second copy of the overview's events
  would pad the screen, not answer its question, so the list ends where its data
  ends.
- **`no-data-hue` on the node screen** — the sheet sets the main series in
  `--chart-1` (white) and spends the accent on the 1 px selection line and the
  restart marker. The metre reads 0.0 % coloured pixels because the only hue on
  the canvas is that 1 px marker and the 11 px status pill; raising it would mean
  colouring a series the style keeps monochrome.
- **`mono` in lint** — deliberate: every figure, time and ID is IBM Plex Mono,
  the style's decision (docs/DESIGN.md §Type). Prose stays Public Sans.
- **`shadow` ×3** — the dialog, the tooltip and the chart's cursor readout, all
  floating UI. Resting cards have no shadow and no border.
- **em dashes ×11** — all of them are the missing-value mark in tables (`—`),
  never prose. Real zeros print as zeros; a missing reading prints as a dash.

## Fixture data to replace

`web/src/data/fixtures.ts` is invented and fixed at `2026-11-01T04:02Z` so the
screenshots and tests are reproducible. M2 deletes the file in favour of the hub
API. Made-up facts to remember:

- four nodes `atlas` (VPS), `beelink` (homelab), `studio` (workstation, disk 91 %),
  `shed` (Raspberry Pi, offline for 2 h 13 min), their OS/kernel/CPU strings,
  addresses from documentation ranges (`192.0.2.x`, `10.0.40.x`);
- seven agent sessions (Codex ×3, Claude Code, Pi, OpenCode, Ollama) and the type
  registry labels;
- six actions and their recorded results, including the failed
  `restart-jellyfin` and the dangerous `update-packages`;
- seven events, the attention list derived from them, and the CPU series (seeded
  walk that ends at the node's live figure).

The action results in the run dialog are the action's recorded last run; there is
no agent to execute anything until M1.
